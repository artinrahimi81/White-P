# Agent Collaboration

## Purpose
Define how agents coordinate, divide work, and combine results.

## Working Principles
- **One owner per task:** Assign each task to a clearly identified agent.
- **Shared context:** Read the project instructions and relevant task history before starting.
- **Clear handoffs:** State the task, inputs, expected output, dependencies, and status when handing work to another agent.
- **No conflicting edits:** Coordinate changes to shared files and avoid overlapping work without agreement.
- **Evidence-based updates:** Report what changed, what was verified, and any unresolved issues.
- **Review before integration:** Check another agent's output for correctness and consistency before accepting it.
- **Escalate blockers:** Communicate missing information, conflicts, or failures instead of guessing.

## Task Lifecycle
1. Receive and understand the assigned task.
2. Check dependencies and existing work.
3. Execute the task within its scope.
4. Validate the result and document evidence.
5. Hand off the result or request review.
6. Mark the task complete only after acceptance.
